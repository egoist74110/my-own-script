## 1. 题材与原则

- 题材：个人发布控制台。把 ADO 上的代码同步 → 构建 → 发布到测试 / 正式环境，也能从 Telegram 远程触发；同时处理工单、AI 会话和本机服务。
- 首要任务：一眼看清哪个任务走到哪一站、停在哪，再一键运行。
- 主角只有一个：**发布线路**。一次运行 = 一趟列车，阶段是站点。其余界面保持安静，不另加装饰。
- 线路只出现在两处：任务（发布线路）和工单（看板列线路）。AI 会话、设置、MCP 只借用两样东西：仓库线路色作为归属标记，状态圆点。

## 2. 令牌

### 颜色

| 名称 | 值 | 用途 |
| --- | --- | --- |
| 纸 | `#FFFFFF` | 详情区、列表 |
| 框架 | `#F3F4F6` | 侧栏、搜索框、悬停 |
| 选中 | `#E9ECF3` | 列表选中行 |
| 墨 | `#1B1D22` | 正文、主按钮底色 |
| 次文字 / 弱文字 | `#5B616E` / `#8B919C` | 说明、元信息 |
| 分隔线 | `#E4E6EB` | 唯一的线色 |

状态色只表示状态，不做装饰：成功 `#1F8A5B`、失败 `#C2372F`、运行中 `#2457D6`、需核实 `#9A5B00`，各配一个浅底（见稿子 `:root`）。

**仓库线路色**：每个仓库固定一种，用在线路、列表小线路、归属标记上。初始四色：Event 青 `#0F8F86`、Front 蓝 `#2F5FE0`、VIP 紫 `#7A4FD6`、API 橙 `#D4651C`。新仓库从预设色板里按顺序分配，用户可改；不允许与状态色相同。

深色模式：沿用同一结构，令牌另给一套值，实现时补稿，不在本草案范围内。

### 字体

- 界面与正文：系统字体（SF Pro + 苹方），不打包第三方字体。
- 等宽（SF Mono，`tabular-nums`）只用于需要对齐的数字：时间、构建号、版本号、命令。不拿等宽字体做标签。
- 字号：正文 13px；列表主行 13px 半粗；详情标题 20px；设置页标题 18px；分组标题 12–13px 半粗；描述正文 14px、行高 1.7、行宽不超过 68 个汉字宽。

### 形状与间距

- 圆角按层级区分：按钮 7px、列表项 9px、分组 10px、窗口 12px。不全局统一一个圆角。
- 阴影只用于窗口本身。分组靠 1px 分隔线，不叠卡片阴影。
- 间距基准 4px；区块间距 22–24px。

## 3. 布局与窄窗规则

| 窗口宽度 | 侧栏 | 列表 | 检查器 |
| --- | --- | --- | --- |
| ≥ 1280 | 212px，图标 + 文字 | 300–320px | 280px 并排一栏 |
| 1100–1279 | 212px | 300px | 打开时浮在详情上方，Esc 或点空白关闭 |
| 960–1099 | 76px（容纳窗口红黄绿按钮），只有图标，悬停显示名称 | 280–300px | 同上，浮层 |

- 详情区最小宽度 560px。低于此宽度时，工具条只保留主操作（运行、只发布），其余收进「⋯」菜单。
- 整页任何宽度下都不出现横向滚动。只有宽表格允许在自己的容器里横向滚动。
- 设置页：侧栏 + 设置分类（200–220px）+ 内容（最大 760px）。窄窗时设置分类保留文字，不收成图标。
- MCP 等单栏页：内容最大 820px，左对齐。

## 4. 组件规则

- **线路**：站点 30px 圆，4px 描边。已到达：实心；当前站：实心 + 外圈光晕；未执行：虚线描边 + 灰色。路段已走过为实线，未走为虚线。站名下方一行小字写结果（用时、构建号、“没有执行”）。
- **列表小线路**：每个任务项底部一条 7px 圆点线路，和详情线路同色同状态。
- **状态标签**：19px 高，图标 + 文字，任何宽度不折行。不能只用颜色表达状态，必须带文字或图标。
- **按钮**：28px 高。主按钮墨色实底，每个视图最多一个；危险操作用红色文字，不用红底。按钮文字写清楚会发生什么（“只发布”“允许一次”），不写“确定”“提交”。
- **表格**：表头与单元格默认不折行；放不下时表格在自己的容器里横向滚动；长描述列显式标为可折行。时间一律显示为本地时间 `MM-DD HH:mm`，不显示 ISO 原文。
- **设置分组**：macOS 系统设置式。一个分组 = 标题 +（可选）一句说明 + 一组行。每行左侧名称和一行小字说明，右侧是值或控件。不把每块内容套成独立卡片。
- **提示条**：只在需要用户行动时出现。先说发生了什么，再说下一步，并把下一步做成按钮放在提示条里。

## 5. 文案

- 从使用者角度命名：“谁能用机器人”，不写“ACL 成员”；“允许 AI 创建工单”，不写“写工具 ado_create_work_item”。
- 不用中点拼接元信息（`A · B · C`）。元信息用图标分隔，或写成正常句子（“09:21 开始，用时 4:23”）。
- 错误不道歉、不含糊：写清哪一步、为什么、怎么办。
- 动作名称前后一致：按钮叫“只发布”，结果就叫“已只发布”。

## 6. 验收

每个页面在 960×600、1280×800、1440×900 三个尺寸下截图检查：

- 不出现整页横向滚动；
- 按钮、状态标签、分页不折行；
- 键盘可以走完主流程，焦点清晰可见；
- 开启“减少动态效果”时没有动画。
